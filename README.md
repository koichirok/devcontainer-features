# Dev Container Features

This repository contains my custom [Dev Container Features](https://containers.dev/features).

## Available Features

| Feature                                | Description                                                                                                        |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| [github-cli](src/github-cli/README.md) | Install the GitHub CLI (`gh`) and persist its configuration in a mounted volume across container rebuilds |
| [gitlab-cli](src/gitlab-cli/README.md) | Install the GitLab CLI (`glab`) and persist its configuration in a mounted volume across container rebuilds |
